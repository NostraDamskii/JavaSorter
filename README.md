# JavaSorter

Учебный проект, реализующий сортировку пользовательского класса User. 
В проекте использованы паттерны программирования: Стратегия, Билдер.
В дальнейшем проект может быть улучшен: можно добавить графический интерфейс для реализации существующих команд.

---
## Возможности
- Понятное меню для работы
- Загрузка коллекции пользователей тремя способами: вручную, из файла и случайными значениями
- Возможность загрузить полученные данные в файл
- Сортировка по всем полям в порядке возрастания и убывания; сортировка пользователей с четными паролями (нечетные остаются на месте)
- Функция подсчета количества вхождений определенного элемента![Uploading Обзор.jpg…]()


---
## Требования
- Формат данных: Имя - String, почта - String, пароль - int
- Формат файла для чтения\записи: Александр;435253;Evgeniy@gmail.com
- java 17

## Структура проекта

| Модуль | Путь | Назначение |
|--------|------|------------|
| **Core** | `src/core/` | Основные сущности: `User` и кастомная коллекция `CustomLinkedList` |
| **Menu** | `src/menu/` | Реализация консольного интерфейса с использованием паттерна **Command** |
| **Service** | `src/service/` | Бизнес-логика: управление пользователями, стратегии заполнения, работа с файлами |
| **Sorting** | `src/sorting/` | Алгоритмы сортировки с применением паттерна **Strategy** |
| **Tests** | `src/tests/` | JUnit-тесты для проверки ключевых компонентов |
